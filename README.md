# Валет пик — демонстрационный макет

Статический лендинг на русском языке: визуальный тестовый макет страницы вымышленного
демонстрационного продукта — игральной карты «Валет пик» (J♠).

## Важно

- Это **демонстрационный макет**. Товар не продаётся.
- Оформление заказа и оплата **не подключены**.
- Нет checkout, ввода платёжных данных, форм сбора контактов, аналитики, cookies,
  внешних виджетов и отправки пользовательских данных.
- Нет выдуманных цены, отзывов, рейтинга, тиража и характеристик изготовления.

## Технологии

- Чистый статический HTML, CSS и небольшой объём JavaScript.
- Без framework, без npm-зависимостей.
- Все изображения — локальные SVG; внешние шрифты, картинки и CDN не используются.
- Относительные пути, поэтому сайт работает и в подпапке `/<repo>/`.

## Локальный предпросмотр

Открывайте страницу через локальный HTTP-сервер (не через `file://`), запустив команду
из корня репозитория:

```
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000/`.

Альтернатива без Python:

```
npx --yes serve -l 8000 .
```
